# attendance-app

## プロジェクト名
COACHTECH　勤怠管理アプリ

## 概要
ある企業が開発したユーザの勤怠と管理が目的の勤怠管理アプリ
管理者側でユーザ勤怠一覧確認と修正申請があった勤怠の承認機能が備わっており一元管理が可能

## 環境構築手順
本プロジェクトを実装するにあたり、下記手順に沿って環境構築を実施
なお下記コマンドなどはWindowsに合わせる

0. 必要なツール
- Docker Desktop
- Git
- テキストエディタ(VS CODE)

1. Laravelプロジェクトの作成（Laravel 10.x） 
2. Laravel Sailのインストール
3. phpMyadminの追加
4. .env ファイルの設定
5. coachtechが提供するBladeの導入
6. フロントエンドのセットアップ (Vite)
7. アプリ起動と初期化
8. アクセス(アプリ→http://localhost, phpMyadmin→http://localhost:8080, Mailpit→http://localhost:8025)
